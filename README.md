# 🚀 ToDesktop Frontend Clone

A pixel-perfect frontend clone of the [ToDesktop](https://todesktop.com/) website, built purely using **HTML**, **Tailwind CSS**, and **vanilla JavaScript**.  
This project replicates the UI/UX of ToDesktop, focusing on responsive layouts, clean code, and interactive frontend components.

---

## ✨ Features

- Full homepage replication with navigation, pricing, and call-to-action sections
- 100% responsive across mobile, tablet, and desktop
- Smooth scroll animations and hover effects
- Lightweight and framework-free (pure HTML, Tailwind CSS, JavaScript)
- Clean, scalable, and semantic codebase

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Niraj-Paswan/ToDesktop-Clone.git

# Navigate into the project directory
cd todesktop-clone

# Open index.html in your browser
```

> **Note:** No build tools or installations needed. Just clone and open!
